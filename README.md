# 💰 Discount Calculator

## 📌 About the Project
The **Discount Calculator** is a simple Python project that calculates the discount amount and final price of a product based on its original price and discount percentage.

It helps users quickly determine how much money they save after applying a discount.

## ✨ Features
- Enter the original price of a product.
- Enter the discount percentage.
- Calculate the discount amount.
- Display the final price after applying the discount.
- Validate the price and discount percentage.
- Display results rounded to two decimal places.

## 🛠️ Technologies Used
- **Python**

## ▶️ How to Run
1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Run the Python file:

   ```bash
   python discount_calculator.py
   ```
